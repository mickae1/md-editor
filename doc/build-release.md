# Build and release

## Three ways to run

| Mode | Workstation requirements | Launch |
|---|---|---|
| Sources | Python 3.10+, Edge | `pythonw mdeditor.pyw [folder]`; shortcut via `install-shortcut.ps1` |
| Development | Python, Node | `python server/app.py sample/Help/Md --port 8765 --no-window` + `npm run dev` in `web/` |
| Compiled | Edge only | `release/mdEditor/mdEditor.exe [folder]` |

In sources mode, the server serves `web/dist`: **this folder is versioned** and must be rebuilt (`npm run build`) and committed after every change to `web/src`. `node_modules` is not needed on the workstations.

## `build.py`

```
pip install pyinstaller      # build machine only
python build.py              # npm ci if needed, npm run build, then PyInstaller
python build.py --skip-web   # reuses web/dist
```

- Generates `build/mdEditor.spec`: two `Analysis` (`mdeditor.pyw` with `web/dist` → `web` and `lang/` → `lang`, and `server/mcp_server.py` without tkinter), two `EXE`, a single `COLLECT`.
- **Folder mode**: `mdEditor.exe` (no console) and `mdeditor-mcp.exe` (console, stdio) share `_internal/` (Python, libraries, UI, `_internal/lang`). Nothing is unpacked at startup (startup ≈ 0.5 s).
- Copies `README.md` into the folder and produces `release/mdEditor-<VERSION>-windows.zip`.
- `build/` and `release/` are ignored by git.

In the executable, `server/app.py` detects `sys.frozen` and reads the UI from `_MEIPASS/web` instead of `web/dist`, and the language files from `_MEIPASS/lang`.

## Version

`VERSION` in `build.py`, `version` in `web/package.json`, `SERVER_INFO` in `server/mcp_server.py` and `server_version` of the `Handler`: update them together.

## Pre-release checklist

1. `cd web && npm run typecheck && npm test && npm run build`
2. `python server/test_mcp.py` and `python server/test_toc.py`
3. `lang/*.json`: same keys in every bundled language file.
4. End-to-end test on a copy of `sample/Help` (see `CLAUDE.md`).
5. `python build.py --skip-web`, then `MDEDITOR_MCP_EXE=release/mdEditor/mdeditor-mcp.exe python server/test_mcp.py`.
6. Run `release/mdEditor/mdEditor.exe sample/Help/Md` and check that it opens.

If a corporate antivirus flags the executables: allow-list them or sign them with a company certificate.
