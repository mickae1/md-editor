# Basic editors

Basic editors let you create and edit entities.

<a id="copy"></a>
## Copy and paste

--8<-- "_snippets/snippet-basiceditors-copy.md"

1. Open the editor
2. Select the entity
3. Apply the changes

=== "Windows"

    Use **Ctrl+S** to save.

=== "Linux"

    Use **Ctrl+S** as well.

??? tip "Tip"
    Double-click an entity to open its editor.
