# Map View

<a id="map-intro"></a>
The map view is the main view of the application. It lets you follow the traffic in real time.

## Interactions

- Select a flight: left click
- Open the context menu: right click
    - The options depend on the element
    - See [Basic editors](GeneralViews-BasicEditors.md#copy)
- Measure a distance: `Shift` + drag
